## Upgrading ALGONETIC

<Callout kind="info" title="Upgrade Safely">
Before upgrading, back up your documentation space and review breaking changes in the release notes above. Test in a staging environment if possible.
</Callout>

Follow these steps to upgrade to the latest version.

<Steps>
  <Step title="Check Compatibility" icon="check-circle">

Review your current setup against the [release notes](#recent-releases). Ensure your API integrations use the new `/v1/` endpoints.

  </Step>
  <Step title="Backup Data" icon="database">

```bash
# Export your documentation space
algonetic export --space my-project --format zip > backup.zip
```

  </Step>
  <Step title="Update Package" icon="download">

<CodeGroup tabs="npm,yarn">
````bash
npm install algonetic@latest
````

````bash
yarn add algonetic@latest
````
</CodeGroup>

  </Step>
  <Step title="Migrate Config" icon="settings">

Update your config file to use the new theme:

````json
{
  "theme": {
    "primaryColor": "#3B82F6"
  },
  "apiBase": "https://api.example.com/v1"
}
````

  </Step>
  <Step title="Restart and Verify" icon="play">

Restart your ALGONETIC instance and verify all pages render correctly.

  </Step>
</Steps>
